How the radar ranks

Implied value = min(ln(TVL / $5M + 1), 4) × (1 + 7-day growth, clamped −50%…+200%) × 1 / (1 + age in years) × $25M. Size matters, but only on a log scale capped at about $268M of TVL — beyond that, more size adds nothing, so a fast-growing young protocol surfaces above a big slow one. Growth is the snapshot's own change_7d; age is days since DefiLlama first listed the protocol. Every row records no token on DefiLlama; protocols whose token already trades are not on this board.

“Records no token” is what the snapshot says — it is not proof a protocol has none.

Data: DefiLlama snapshot, 14 Nov 2026. Implied values are this radar's own model, not a prediction that a token launches or what it will trade at. Farm plans are suggestions, not financial advice.
